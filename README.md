# E-Commerce Sales Dashboard (Excel)

## Project Overview

An interactive Excel dashboard designed to analyze e-commerce sales performance and provide insights into revenue, orders, customers, and product trends.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting

## Key Metrics

* Total Revenue
* Total Orders
* Average Order Value
* Top Products
* Sales Trends

## Dashboard Features

* Interactive filters and slicers
* Sales performance analysis
* Product-wise insights
* Customer behavior analysis
* Dynamic visualizations
